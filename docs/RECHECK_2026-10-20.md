# Recheck of the last two updates

This audit supersedes earlier claims of completed independent-letter animation
or a natively verified Done flow. Fixes below are in source, not a tested build.

## Defects corrected

- The rectangular logo slices cut through neighbouring letters. Replaced with
  one continuous mesh and sequential letter-area bounce, returning to the exact
  original quad. Independent letter motion still needs separate letter layers.
  Splash duration now accommodates motion and any supplied chorus clip.
- Done blocked the UI while waiting for disk writes. It now locks painting
  input, awaits the existing writer, saves any remaining dirty revision,
  refreshes missing previews, then celebrates and fades. Save failures keep the
  artwork open and restore input. Repeat taps are blocked. Focus/pause still
  flush synchronously for durability.
- Disabled palettes continued moving. Rainbow/Eraser now stop and settle them;
  hide/reopen restores centered cells. Wheel scrolling targets whole choices.
- Doubling the brush previously changed only the paint radius. A reusable,
  non-interactive painting cursor now displays the original selected tool icon
  at twice its toolbar dimensions. This is not drag-from-toolbar interaction.
- Menu mascots could exceed narrow tabs. They now fit the collapsed tab width,
  preserve aspect ratio, and reveal labels only when expansion provides room.
  Stable tabs no longer recalculate every frame.
- Button callbacks duplicated tap sounds. Shared pointer feedback now owns tap
  audio. Sparkle bursts occur only on actual release, not forced pause/save/tool
  changes. Sound off stops one-shots; Motion off clears existing particles.
- Save encoding made two avoidable full-page byte copies. It now hashes and
  compresses its owned stream buffer, avoiding approximately 22.5 MiB of temporary
  arrays at 1536 square. Oversized files are rejected before full reads. Save
  format/checksum/alternate slots remain compatible. Memory is not profiled here.
